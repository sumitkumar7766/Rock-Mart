# Rock Mart

Welcome to Rock Mart, your one-stop shop for all things rock music! Whether you're a fan of classic rock, hard rock, or alternative rock, we've got you covered with a wide selection of merchandise, albums, and memorabilia.

## Features
- Extensive collection of shoping items
- User-friendly interface
- only frontend use HTML and CSS
- Responsive design for all devices

## Getting Started
To get started with Rock Mart, simply clone this repository to your local machine:
```git clone https://github.com/yourusername/rock-mart.git
```
Then, open the `index.html` file in your web browser to explore the shop.

## Note :- This is a basic website made using only HTML and CSS for practice purpose. There is no backend functionality implemented.
